Light Survey へ ようこそ

心地よく働くための月次サーベイ。 自分のコンディションと（メンバーは）リーダーへの評価を、毎月10分以内で。 早期に気づき、早期にフォローできる組織を一緒につくります。

月次サイクル 10分以内で完了 全社員対象 招待制（@light-inc.com）
1

このサーベイの目的

なぜ毎月、回答するのか
📊

コンディションを継続的に把握する

一人ひとりが心地よく働けているか。月に一度「最近どう？」を構造化して聞く仕組みです。

🎯

マネジメントを見える化する

メンバーからの評価と役員の期待を組み合わせて、リーダーのマネジメントが機能しているか測定します。

🤝

早期に気づき、早期にフォロー

コンディションが低下した時に、1on1等で素早く対応できるようにします。

2

3つのロール

自分のロールは管理者から事前に案内されます
ロール 対象者 サーベイで答えること
メンバー 現場メンバー リーダー評価 ＋ 自身のコンディション
リーダー チームを持つ管理職 自己評価 ＋ チーム観察 ＋ 自身のコンディション
役員 経営層 / 執行役員 各リーダーへの期待比重（4軸の配分）＋ 全社レポート閲覧
3

利用ステップ

ログインから回答完了まで
STEP1

本番 URL を開く

ブラウザで以下の URL にアクセスしてください。

https://light-survey.light-5d5.workers.dev/

ブックマーク登録しておくと次回からアクセスがスムーズです

STEP2

Google アカウントでサインイン

「Google でログイン」ボタンを押すと Google のアカウント選択画面に進みます。@light-inc.com の会社アカウントを選択してログインしてください。

個人 Gmail ではログインできません。必ず会社の Google アカウントを使用してください

「Google アカウントでログイン」ボタンを押す
STEP3

ホーム画面に到達

ログインに成功すると、自分のロールに応じたホーム画面が表示されます。左下に自分の名前とロールバッジが見えればOKです。

ロール表示が違う場合は管理者（Slack）までご連絡ください

今月のサーベイカードと回答状況が表示される
STEP4

サーベイページを開く

左メニューの「サーベイ」をクリック。当月のサーベイカードが表示されます。「コンディション」と「チーム状況」の 2 種類があり、それぞれ独立して回答できます。

「未回答」または「回答中」が付いているカードを順に開いてください

サーベイ一覧から今月分を選択
STEP5

設問に答える（選択肢を押すだけ）

チャット形式で設問が表示されます。しっくりくる選択肢を1つ押してください。次の設問に自動で進みます。

各設問は 4 段階。コンディションは「充実 / 良好 / 要注意 / 要ケア」、マネジメントは「卓越 / 期待通り / 注意 / 要改善」のニュアンスです

4択から選ぶか、自由入力で回答
STEP6

自由記述（任意）

最後にリーダーへ伝えたいことがあれば入力欄に記入してください。特にない場合は「特になし」ボタンを押せばOKです。

自由記述はリーダー本人と一部の権限者のみが閲覧します

「特になし」または自由入力で送信
STEP7

送信して完了

全設問に回答し終えると完了画面に移ります。「回答を送信して終了」ボタンを押すと、回答が保存されます。

送信後も期間内なら何度でも修正可能です

「回答を送信して終了」ボタンで完了
4

何を答えるのか

ロールごとに設問の内容が変わります
ロール 答える内容
メンバー
  1. 自分のリーダーへの評価（目標達成への推進 / 強みの活用 / メンバーの育成 / 他チーム・経営層との連携）
  2. 自身のコンディション（帰属意識 / やりがい / 風土 / 成果実感）
リーダー
  1. 自分のマネジメント自己評価 ＋ 重み配分
  2. チーム全体の観察
  3. 自身のコンディション（メンバーと同じ 4 軸）
役員 各リーダーへの期待を 4 軸（目標達成への推進 / 強みの活用 / メンバーの育成 / 他チーム連携）で合計 100% 配分。直近 1 ヶ月分のみ未回答対象。
5

ロール別に見える画面

ログイン後にアクセスできるページの全体像
メンバー

ホーム / サーベイ / マイページ

レポートやダッシュボードへはアクセスできません

ホーム

今月のコンディションサーベイとチーム状況サーベイのカード。両方とも独立して回答できる。

サーベイ一覧

コンディション (4 軸 self) と チーム状況ヒアリング が並ぶ。回答済みでも期間内なら再回答可能。

/survey

マイページ

自分の現在のロール・チーム・できることが表示される。権限変更の依頼導線つき。

/me
リーダー

ホーム / サーベイ / レポート / マイページ

レポートは「自チーム」のみ閲覧可能 (他チームは見えない)

ホーム

マネジメント自己評価 + チーム観察 + 自身のコンディションが 1 つのフローに統合。自チームレポートへのショートカットも。

/

サーベイ一覧

「マネジメント自己評価」カード 1 枚で、4 軸の重み配分・自己評価・チーム観察・自身のコンディションまで連続回答。

/survey

自チームレポート

メンバーからの 4 軸評価・期待比重・加重総合スコア・自己 vs メンバー評価のギャップ・エンゲージメント 4 軸・スコアトレンド・AI 考察ハイライト。

/reports

マイページ

「自チームのレポート閲覧」が「現在できること」に追加で表示される。

/me
役員

ホーム / サーベイ / レポート / ダッシュボード / 管理

全社の全データが閲覧でき、ユーザー招待・期間運用も担当

ホーム

配下リーダーの状況、全社サーベイの進捗、各リーダーへの期待配分入力導線、ユーザー管理 / ダッシュボード / レポートへのショートカット。

/

全社レポート

全社平均 + リーダー別詳細を一覧。マネジメント 4 軸の比較・スコアトレンド・各リーダーの AI 考察ハイライトまで。

/reports

ダッシュボード

マネジメント総合 / エンゲージメント総合 / 回答率 / 最大ギャップ + リーダー別スコア・月次スコアマトリックス・メンバーコンディションシート・コンディション月次トレンド。

/dashboard

ユーザー管理

全社員のロール・チーム・状態を一覧で編集。招待ダイアログから新規メンバー追加 (Resend で招待メール自動送信)。

/admin/users

期間管理

「コンディション」「チーム状況」の 2 種類のサーベイ期間を独立して開閉。月次の運用画面。

/admin/periods

困った時は

気軽にお声がけください

🔐 ログインできない / ロールが違う

管理担当（HR）に Slack（個別チャンネル等）でご連絡ください。

❓ 設問の意味が分かりづらい

「迷いがある」「物足りない」など、しっくりくる選択肢を選んでOKです。深く考えすぎず、率直に。

📨 招待メールが届かない

メールボックスの迷惑メール / プロモーションタブを確認してください。それでも見つからない場合は HR にご連絡ください。

📱 スマホでも使える

iPhone / Android のブラウザに最適化されています。サイドメニューは左上のハンバーガーボタンから。
